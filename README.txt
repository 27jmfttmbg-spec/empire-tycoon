EMPIRE — THE WATERFRONT | iPhone-friendly 3D tycoon

UPLOAD TO YOUR EXISTING GITHUB REPOSITORY
1. Unzip Empire-Tycoon-Phase-02.zip in the iPhone Files app.
2. Open github.com/27jmfttmbg-spec/empire-tycoon in Safari.
3. Replace the repository root index.html with the index.html in this folder.
4. Upload all FIVE files in the models folder to the repository's models/ directory, using these exact names:
   coffee.glb, exchange.glb, hotel.glb, mansion.glb, steakhouse.glb
5. Commit changes to main. Wait 1–3 minutes, then open:
   https://27jmfttmbg-spec.github.io/empire-tycoon/
6. Reload Safari. For cached old versions, close the tab and reopen it.

GAMEPLAY
- Fixed cinematic camera and permanent daylight
- Nine buyable properties in a mirrored city layout
- Five real original GLB architecture models, reused as mirrored districts
- Purchases, ten upgrade levels, passive income, four-hour offline earnings
- Six objectives with one-time cash rewards
- Portfolio and auto-saving on the same device/browser
- Click property labels or the buildings themselves

REQUIREMENTS / NOTES
- An internet connection is required to load the Three.js library.
- For security reasons, browsers may block ES modules if you open index.html directly from Files. Play via GitHub Pages or a local HTTP server.
- Your progress is saved in browser localStorage, not synced across devices.
- This is a playable high-quality prototype, not a production AAA release.
- This package was built locally; it has not been published to GitHub.
